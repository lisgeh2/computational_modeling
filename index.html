Suggested experiments ＋
  1. Predict whether a linear classifier can learn the task, then test it.
  2. When training stalls, add units or increase training updates.
  3. Hold one feature constant and vary the other. Where does the prediction change?
  4. Compare hidden activation maps before and after training.
  5. Repeat training from another seed and compare internal representations.
  6. Disable a hidden neuron and inspect which predictions change most.
  7. Locate errors on the testing set without changing the weights.
How the model works

Learning is a sequence of small corrections.

Each full-batch update calculates the difference between the model’s probability and the correct category, then adjusts weights using gradient descent. A single “update” is one complete pass over the training examples.

Each input is normalized by the same fixed scale of 0–100. The network receives numeric features; it does not extract them from image pixels.

Output probability p(B) = sigmoid(z)

Loss = −[y log(p) + (1−y) log(1−p)]

Hidden units use tanh. The output uses sigmoid.
Data provenance

About the dataset

The available environment could not retrieve the public Dryad workbook or its codebook, so this build uses reproducible local synthetic examples matching the requested category structures. No human responses or human results are invented.

When the workbook is available, it can be bundled as a local Excel file. The app is structured to keep training/test sets separate and to use category labels, not participant responses.
