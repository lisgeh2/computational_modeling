About the task and data

Loss measures prediction error; accuracy measures correct category predictions.

The public Dryad workbook and codebook could not be retrieved in the build environment. These reproducible examples follow the category rules and contain no human responses or human results. XOR is a synthetic classroom extension.

Features are displayed on a 0–100 scale as mapping placeholders, not physical measurement units. The network uses two numeric inputs, tanh hidden units, a sigmoid output, and full-batch gradient descent.
